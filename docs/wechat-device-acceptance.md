## 2. 已完成的真机验收（2026-11-12，徐晨帆）

1. 开发者工具打开 `miniapp`（`config.js` 指向正式域名），点「预览」，手机微信扫码打开小程序。
2. 小程序点「微信一键登录」：该微信在生产库未绑定 → 选择绑定或注册 → 完成绑定并显示账号卡。
3. 电脑打开 `https://collect.allwayso.top/login`，点「用微信登录」，页面出现 8 位配对码与倒计时。
4. 小程序点「登录网站」，输入该 8 位码并确认。
5. 结果：网页自动进入工作台，**全程未输入密码**。

验收范围：真实 `wx.login` 换取 openid、绑定、网页配对登录、会话建立。未覆盖：小程序发布、普通公众入口、手机密码遮蔽以外的异常分支。

## 3. 让其他成员独立做真机验收

前置：该成员需要有自己的微信、一台 Windows 或 Mac（微信开发者工具不支持 Linux）、以及一个生产账号密码。

1. **加入项目成员**（管理员操作）：https://mp.weixin.qq.com/ → 管理 → 成员管理 → 添加成员，填其微信号或扫码邀请，权限选「开发者」。只加「体验成员」无法打开开发版预览。
2. **安装开发者工具**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
3. **取代码**：`git fetch https://github.com/xcfsllsz/SADP-final.git xcf`，切到该分支后打开 `miniapp` 目录；`project.config.json` 已含 AppID，不要修改。
4. **预览装机**：开发者工具点「预览」，用**自己的微信**扫码。提示无权限说明第 1 步没生效。
5. **绑定或注册**：小程序点「微信一键登录」；未绑定时可选「用已有账号绑定微信」（输入生产账号密码）或「注册采集者账号」。核验者、第三方、管理员仍由管理员分配。
6. **网页配对**：浏览器打开正式站登录页 → 点「用微信登录」→ 记录 8 位配对码 → 小程序「登录网站」输入确认 → 网页自动登录。
7. **复登验证**：小程序退出登录后重新「微信一键登录」，应免密直接进入账号卡。

## 4. 已知失败与处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 小程序确认时提示「请求失败（HTTP 403）」 | 小程序只保存了 `JSESSIONID`，未回传 `XSRF-TOKEN`，配对确认被 CSRF 拒绝 | 使用含 `ae6c3be` 的代码重新预览；服务端无需改动 |
| 配对码无效/已过期/已使用 | 8 位码五分钟有效且一次性 | 网页点「取消微信登录」后重新点「用微信登录」取新码 |
| 小程序提示无权限或页面不存在 | 该微信不在项目成员内，或小程序未发布 | 先按第 3 节第 1 步加入成员 |
| 登录提示账号或密码错误 | 用于绑定的是生产库账号，与本机开发库不同 | 使用服务器 `accounts.json` 里的账号密码 |
| 网页没有出现「用微信登录」按钮 | 正式环境未配置小程序 AppID/Secret，或页面缓存 | 先查 `mini/status` 是否为 `configured:true`，再强制刷新页面 |

## 5. 回报格式

复验完成后在本文件追加或回复 PR #8，写明：成员、时间、部署版本 SHA、小程序代码 SHA（含 `ae6c3be` 与否）、绑定或注册的账号名与该环境 userId、第 2 节第 4–5 步是否通过；失败时附小程序与网页两侧的提示原文。
